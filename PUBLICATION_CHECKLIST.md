# Publication Checklist

Prima di pubblicare o aggiornare il mirror pubblico:

- [ ] Nessun token o credenziale.
- [ ] Nessun numero di telefono privato.
- [ ] Nessuna email privata non necessaria.
- [ ] Nessun path locale assoluto.
- [ ] Nessun budget dettagliato o file economico.
- [ ] Nessun documento contrattuale.
- [ ] Nessuna immagine, PDF, DOCX o archivio pesante.
- [ ] Solo markdown testuale.
- [ ] Presente `CONTEXT_VERSION`.
- [ ] Presente AI Log nei file principali.
- [ ] Chiaro che il mirror non e fonte di verita.
